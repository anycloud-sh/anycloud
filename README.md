# anycloud

Deploy containers to any cloud provider.

## Installation

macOS with Homebrew:

```bash
brew install anycloud-sh/tap/anycloud
```

Installer script:

```bash
curl -fsSL https://get.anycloud.sh | sh
```

To inspect the installer first:

```bash
curl -fsSLo install.sh https://get.anycloud.sh
less install.sh
sh install.sh
```

## Usage

```bash
anycloud --help
```
