# Security

Report a vulnerability privately through GitHub's
[security advisories](https://github.com/anycloud-sh/anycloud/security/advisories/new),
not in a public issue or pull request. If that form is unavailable, email
support@anycloud.sh. Include the affected version
(`anycloud --version`), the steps to reproduce it and its impact.

Security fixes ship in the next release; there are no long-term support
branches.
