# Gateway Tests

This directory contains tests for cloud provider gateway implementations.

## Structure

- `aws.spec.ts` - AWS cloud provider tests
- `azure.spec.ts` - Azure cloud provider tests
- `gcp.spec.ts` - GCP cloud provider tests
- `cloudflare.spec.ts` - Cloudflare DNS gateway tests

## Future Work

Gateway tests will be added to validate cloud provider integrations, VM provisioning logic, and DNS management functionality.
